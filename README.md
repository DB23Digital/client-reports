# client-reports

Published SEO dashboards, one folder per client, served via GitHub Pages.
Generated and pushed by `publish_client_dashboard.py` in the `seo-dashboard`
repo -- do not edit by hand, changes are overwritten on the next publish.

Contains client-safe output only (no cross-client data, no raw GSC/GA4
snapshots). The source repo stays private; this one is public so the links
work without sign-in.
